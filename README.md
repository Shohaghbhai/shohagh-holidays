# Shohagh Holidays (সোহাগ হলিডেজ) - Bangladesh Domestic Tour Agency

A modern, clean, responsive Travel & Tour Agency web application optimized for Bangladeshi domestic tour packages (Sajek Valley, Saint Martin's Island, Sundarbans Mangrove Safari, Tanguar Haor Luxury Houseboats, Cox's Bazar Marine Drive, Sylhet, and Bandarban).

## 🚀 Key Features

- **Direct WhatsApp Booking Engine (+8801572596078)**: Every package card and detail modal has a direct WhatsApp booking button with auto-filled message: `Hello, I want to book: [Package Name] - Price: [Price]`.
- **Protected Real-Time Admin Dashboard (`/admin`)**: Password protected (`admin123`). Add, edit, or delete domestic packages, bus routes, ship schedules, and update prices in BDT (৳) in real-time without editing code.
- **Bus & Ship Ticketing**: Saint Martin sea cruise ships (Bay One, Keari Sindbad, MV Baro Awlia) and intercity AC sleeper buses (Green Line, Shohagh, Saintmartin Travels, Desh Travels).
- **Travel Tips & Practical Guides**: Blog grid inspired by greenbelt.com.bd for Bangladeshi travelers.
- **100% Free Hosting Ready**: Pre-configured with `vercel.json` for 1-click deployment on Vercel with free SSL.
- **Office Location**: Toyenbee Bhaban, Toyenbee Circular Road, Motijheel, Dhaka-1000, Bangladesh.

## 🛠️ Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📦 Build for Production

```bash
npm run build
```

## 🌐 Deploy to Vercel (Free)

1. Push this repository to GitHub.
2. Go to [vercel.com](https://vercel.com) and import the repository.
3. Click **Deploy**. Vercel will build and host it automatically.
